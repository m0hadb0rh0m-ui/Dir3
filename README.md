# درع (Dir3)، تطبيق حماية وتنظيف للأندرويد

تطبيق Kotlin + Jetpack Compose يعمل بالكامل على الجهاز. لا يحتوي إذن إنترنت ولا إعلانات ولا خوادم.

## الميزات الحالية (المرحلة 1)
- **الرئيسية:** مراقبة مباشرة للرام والتخزين والبطارية وحرارتها، مع ملاحظات.
- **تنظيف:** البحث عن الملفات الكبيرة (+50 ميجا) والمؤقتة وAPK، والحذف بعد تأكيدك.
- **التطبيقات:** تقدير خطورة كل تطبيق مثبّت حسب صلاحياته ومصدر تثبيته وخدمات الإعاقة المفعّلة، مع اختصار لإعدادات التطبيق.
- **الروابط:** تحليل محلي للرابط (http، IP، Punycode، روابط مختصرة، حيلة @، امتدادات مشبوهة...).

## ما لا يفعله (قيود أندرويد، وليس تقصيراً)
- لا «ينظّف الرام»، لأن أندرويد يديرها بنفسه.
- لا يفحص داخل ملفات التطبيقات الأخرى.
- ليس مضاد فيروسات بقاعدة تواقيع، فهو أداة وعي وتنظيف.

## طريقة البناء

### أ) بدون كمبيوتر أو Android Studio (GitHub Actions، مجاني)
1. أنشئ حساباً على github.com ومستودعاً جديداً (Repository).
2. ارفع كل محتويات هذا المجلد كما هي، مع مجلد `.github`.
3. من تبويب **Actions** شغّل **Build APK**.
4. بعد دقائق نزّل `dir3-apk` من صفحة التشغيل، فك الضغط وثبّت `app-debug.apk`.
   (فعّل «التثبيت من مصادر غير معروفة» لمتصفحك أو مدير الملفات.)

### ب) Android Studio
افتح المجلد، انتظر مزامنة Gradle، ثم Build ثم Build APK.

## ملاحظات
- الكود لم يُترجم أو يُجرَّب على جهاز في بيئة الكتابة، فقد تظهر أخطاء بناء صغيرة. أرسل لي نص الخطأ وأصلحه.
- إذن «الوصول لكل الملفات» ممنوع على متجر جوجل بلاي لهذا النوع من التطبيقات، لذلك التثبيت يكون مباشرة كملف APK.
